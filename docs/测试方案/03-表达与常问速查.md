# 表达与常问速查

面试或汇报前用这份文档快速过一遍：一分钟怎么讲测试方案、常见问题怎么答、哪些点一定要说到。

---

## 一、一分钟讲清「我怎么做交易所测试」

按下面顺序说，控制在 1 分钟内：

1. **分层**：单元测撮合和风控规则；接口测下单撤单、充值提现，重点幂等和限流；场景测从注册到提现整条链路；对账测余额和流水、订单和成交、DB 和缓存一致；再压测看限流、熔断、降级是否生效。
2. **核心原则**：交易所核心是钱和单子不能错，所以优先保资金和订单一致性，P0 是钱错、单子错、提现错，再补风控和体验。
3. **对账**：余额等于昨日余额加流水汇总；订单的成交汇总和成交表对上；冻结和未成交挂单对上；有业务单号和状态方便排查。
4. **质量门禁与准出**：发布前设质量门禁（P0/P1 清零、核心与回归通过、对账无差异）；准出标准与发布红线共识，不达标不发布；质量左移（需求评审、冒烟通过才提测）；大版本/大促前全链路压测，结果纳入准出。
5. **举例**：充值同一笔 tx 多次回调只入账一次；强平线到了就平仓、盈亏进余额；资金费谁付谁收方向对；限额到了就拒。

## 二、常见问题与回答要点

| 问题 | 回答要点 |
|------|----------|
| 你了解交易所业务吗？ | 分几块：用户与账户、资产与钱包、交易与订单、行情、风控、清算；核心是钱和单子不能错；主流程是注册→充值→下单撮合→成交→提现；现货和合约的差别是合约多杠杆、强平、资金费、穿仓。 |
| 现货和合约测试有什么不同？ | 合约多出保证金、强平线、资金费、穿仓、标记价/指数价；测试要覆盖保证金率计算、强平触发与顺序、资金费方向、穿仓与风险金、取价来源。 |
| 撮合怎么测？ | 价格时间优先、部分成交与撤单、市价吃盘口；订单状态和成交明细、账户冻结和余额在 DB/缓存/推送里一致；边界如 0 数量、超限、重复撤单幂等；撮合和账户异步时要造延迟做一致性校验。 |
| 强平 / 清算怎么测？ | 保证金率到线就强平、用**标记价/指数价**不用最新价（防**插针**误爆）；强平后仓位为 0、盈亏进余额、流水对；**加仓/减仓**测占用与均价重算、减仓释放保证金与实现盈亏；资金费谁付谁收、结算后余额流水一致；穿仓从风险金扣、流水能体现；定时任务跑全、失败要重试或告警。 |
| 插针是什么、为什么用标记价？ | **插针**=盘口瞬间剧烈波动、价格一根针打上去或打下去；若用最新成交价算强平会误爆很多仓位。所以强平和资金费用**标记价/指数价**（限幅、延时），不用最新价，避免被插针带崩。测试要验证取价来源和异常行情下限幅/延时。 |
| 风控测什么？ | 限额到限就拒、错误码明确、配置生效；熔断触发时只许撤单或拒新单、恢复后正常；降级后非核心关或限流、核心（下单撤单查余额）仍可用、恢复后全回来；异常行为限频或封禁、有记录不误伤；黑名单命中就拒、不扣钱；敏感操作二次验证。 |
| 熔断和降级有什么区别、怎么测？ | **熔断**：到阈值（涨跌幅、错误率）就缩范围或停（如只许撤单）；测触发条件满足时接口行为、恢复后正常。**降级**：压力或依赖异常时关非核心保核心（如关推送保交易）；测开关/条件生效后该关的不可用、核心可用、恢复后全回来。压测和混沌时要验证二者在高压下真的生效且不误伤核心。 |
| 钱错了怎么排查？ | 先对账：余额是否等于上时点余额加流水汇总；流水是否漏记、重复、方向反；冻结是否和未成交挂单对上。再查订单和成交是否一致、提现是否回滚、强平是否执行。 |
| 你怎么保证数据一致性？ | 对账：余额与流水、订单与成交、冻结与挂单、链上与内部；唯一业务单号和状态；关键操作有流水和时间戳；定时对账任务和报表/导出便于自动化。 |
| 测试优先级怎么定？ | P0 钱错、单子错、提现错；P1 余额流水对不上、撮合错、风控没拦住；P2 展示和体验。先保 P0 再按发版节奏补 P1/P2。 |
| 区块链不可逆，真有 bug 怎么处理？ | 事前：测试网充分测、关键路径对账与告警、提现限额/白名单/大额延迟、合约可升级或 pause；事后：链上不能改，只能业务兜底（准备金补偿、联系对方）；流程：止损→对账→补偿→复盘→修 bug 加用例。设计上尽量让错发生在链下（可回滚），链上少做不可逆操作。 |
| 质量门禁 / 准入准出怎么做的？ | **质量门禁**：发布前必须通过的检查项（P0/P1 清零、核心用例与回归通过、对账无差异、无发布红线问题），不通过卡发布。**准入**：提测前提（需求评审通过、冒烟通过、环境就绪）。**准出**：满足门禁、无红线、回归通过、签字；大促前可加全链路压测通过。**发布红线**：资金/订单 P0、对账不平等必须拦停的类型。**质量左移**：需求评审参与、冒烟通过才提测，减少逃逸。 |

## 三、面试前过一遍清单

- [ ] 能在一分钟内说完：分层 + 核心原则 + 对账 + 举例。
- [ ] 能说清交易所分几块、主流程、现货 vs 合约。
- [ ] 能说清撮合（价格时间优先、部分成交、一致性、边界）。
- [ ] 能说清杠杆与强平（开仓/加仓/减仓/平仓、保证金、强平线、标记价/指数价防插针）。
- [ ] 能说清清算（资金费、穿仓、风险金、定时任务）。
- [ ] 能说清风控（限额、熔断、降级、异常检测、黑名单）；能说清熔断 vs 降级（到线就停 vs 关非核心保核心）、怎么测。
- [ ] 能说清「钱错了怎么排查」：对账流水、冻结、订单成交、提现回滚、强平执行。
- [ ] 能举 1～2 个具体用例：如充值幂等、强平到线、资金费方向、限额到限就拒。
- [ ] 能说清「链上不可逆，有 bug 怎么办」：事前预防（测试、限额、对账告警）、事后兜底（链上不能改、业务补偿）、设计上错尽量在链下。
- [ ] 能说清**质量门禁、准入准出、发布红线、质量左移、全链路压测**：门禁项与准出标准、红线类型、左移做法、压测纳入准出。

过完上面几条，再扫一眼 01 的「术语速查」和「掌握后你能说清什么」、02 的「一分钟说清」「质量门禁」和「链上不可逆」一节，即可上场。
